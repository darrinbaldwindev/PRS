# Marketing Role & Next Actions

**Owner:** Marketing Overseer
**Date:** 2026-09-03

## Marketing requirements

- Validate the target buyer for project assurance: AgentOS users, development teams, project owners and/or organisations operating autonomous work.
- Position PRS clearly as an independent assurance/evidence layer, not a second agent runtime.
- Validate the strongest pain points: verification burden, evidence gaps, drift, readiness and autonomous-work integrity.
- Develop proof-led demos showing Inspect → define → implement → verify → record → continue.
- Test packaging hypotheses without making pricing promises.
- Build technical SEO/AEO around project assurance, verification and evidence concepts.
- Maintain strict separation between candidate capability and implemented capability.

## Immediate action

Use the existing position — “AgentOS does the work. PRS proves the work is being done correctly.” — as the working message, then validate buyer/problem fit before broad commercialisation.

## Boundary
PRS marketing must not claim assurance outcomes that the evaluator cannot currently prove.
